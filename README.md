## Devlog
### Write a metaphor for how you would describe the relationship between Components, GameObjects, and Scenes to another student. In the first in-class activity, we described Components as being the “building blocks” of GameObjects, and GameObjects as the “building blocks” of Scenes; come up with your own creative way to visualize and describe this relationship without using the phrase “building blocks”.
Scenes are like a bucket. A very large one, even perhaps infinite. But like most buckets, you can put stuff inside of them. In this case, GameObjects are like smaller buckets. Some are shaped differently, but they're all smaller and more personalized than the main scene bucket. Components are things you can put into those smaller buckets. Some only fit into certain buckets, and others are necessary for a smaller bucket to do it's function and properly fill up the main bucket.
